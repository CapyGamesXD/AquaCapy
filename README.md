# AquaCapy

It's a super simple physics app written in Go! You drop some randomly generated circles and play around with them! 

## More info:
I used Go since it's incredibly fast!! Using Ebitengine for rendering works great. I pre-render a circle, since rendering a low-res image is MUCH more efficient than rendering individual circles on every frame. 
This is my first real Go project! I made one learning project prior to this, but - considering I never finished it, I don't think that counts :D 
Because of that, it's very likely got some bugs! Please - if you find one, report it to me :D
